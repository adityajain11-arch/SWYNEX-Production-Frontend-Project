API Integration & Deployment Guide

Project Architecture

This application is designed with **modular JavaScript components**, standard CSS utility patterns, real-time API state management, and failover network mechanisms.

  • Live API Fetching: Consumes CoinGecko API (`/coins/markets`) for live pricing and 7-day sparkline charts.
  • Error Handling & Retry: Automatic fallback to realistic mock financial data if API rate-limits or network failures occur.
  • User Interactivity: Real-time search, category tab filtering, sorting, persistent LocalStorage watchlist, dynamic SVG charting, and modal details.

Deployment Step-by-Step Instructions

Deploying to GitHub Pages

  1. Commit this index.html file to your repository root directory.
  2. Go to your repository on GitHub → Settings → Pages.
  3. Under Build and deployment, set Source to Deploy from a branch.
  4. Select your branch (e.g., main) and folder (/root), then click Save.
  5. Your live URL will be ready at: https://<username>.github.io/<repo-name>/

Deploying to Vercel

  1. Log in to Vercel.com and click Add New Project.
  2. Import your GitHub repository: SWYNEX-API-Integration.
  3. Keep standard default settings and click Deploy. Vercel will instantly generate a live production domain.
